# Asmaa Salah — Web Portfolio

This is a standalone responsive portfolio page.

## Preview locally
Open `index.html` in a browser.

## Publish under the existing GitHub Pages site
1. Download and extract `asmaa_web_portfolio.zip`.
2. In the `asmaa588/asmaa588.github.io` repository, create a folder named `portfolio`.
3. Upload `index.html` into that folder.
4. Commit to the branch used by GitHub Pages.
5. After deployment, visit: https://asmaa588.github.io/portfolio/

This page is self-contained (HTML + CSS + small JavaScript). It does not overwrite the existing Chirpy homepage.
